Fierydits1, part of the FieryDits project, helps its operator turn selected images into short videos and publish them to connected accounts on YouTube, Instagram and X.

How it worksHow data is used

From source to post

One workflow, three stages.

01 / ORGANIZE

Select source media

The operator configures Google Drive folders for source images, processing, finished media and job records. Account setup can create a separate folder structure.

02 / PREPARE

Create a short video

The automation downloads selected media and prepares a video, with configured motion and text. Job records help track processing and recover from interrupted runs.

03 / PUBLISH

Send to connected accounts

Enabled publishing workflows send the prepared video and accompanying text to accounts the operator has connected and authorized.

Permission comes first.

Google authorization lets the app access configured Drive content and, when publishing is enabled and authorized, upload to YouTube. Fierydits1 uses YouTube API Services.

Instagram uses an account access token. X automation uses a saved browser login. The operator chooses the connected accounts and enabled workflow.

Read about access, storage and deletion

Built for personal use.

This project is operated for its owner's content workflow. It is not a public sign-up service. New multi-account onboarding is separate from the existing publishing workflow; completing onboarding does not start posting.

This information site contains no account sign-in form and does not collect your account tokens.
